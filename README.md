# ❌⭕ Jogo da Velha - React & Vite

## 🎯 Objetivo do Projeto
Este projeto consiste na refatoração do clássico **Jogo da Velha**, tomando como base o tutorial oficial do React para evoluí-lo para uma aplicação moderna, organizada e elegante. 

O objetivo principal é transformar o código original em uma estrutura profissional dividida em componentes reutilizáveis, onde cada parte da tela — como o tabuleiro, os botões e o histórico — cuida apenas da sua própria responsabilidade. 

### Principais Funcionalidades:
* Alternância automática de turnos entre os jogadores (`X` e `O`).
* Validação em tempo real de vitória e empate ("deu velha").
* **Viagem no Tempo (Histórico):** Navegação por jogadas anteriores da partida.
* Layout responsivo e estilização isolada.

---

## 🛠️ Tecnologias Utilizadas
* **[React](https://react.dev/):** Biblioteca principal para construção da interface baseada em componentes e Hooks (`useState`).
* **[Vite](https://vitejs.dev/):** Ferramenta de build ultrarrápida para desenvolvimento front-end.
* **[CSS Modules](https://github.com/css-modules/css-modules):** Estilização escopada por componente para evitar conflitos de estilo global.
* **[Bootstrap](https://getbootstrap.com/):** Framework para estruturação de layout responsivo e utilitários visuais.

---

## 🔤 Linguagens Utilizadas
* **HTML5:** Estruturação semântica.
* **CSS3:** Estilização com variáveis e metodologia BEM.
* **JavaScript (ES6+) / JSX:** Lógica do jogo, gerenciamento de estado imutável e renderização de componentes.
